The Problem

In this era of information overload, it is increasingly difficult to evaluate whether a news article is credible, how it frames its subject, or where its sources actually stand. Most people read headlines without any tool to help them think critically about what they are consuming.

My Solution

I built NewsLens, a credibility analysis tool that lets users paste any news article and receive a structured breakdown of its credibility signals, framing, and source context. Powered by the Gemini 2.5 Flash API with a Groq Llama fallback for reliability, the application processes articles through a carefully engineered prompt pipeline with JSON validation and fence stripping. It also surfaces trending headlines via the NewsAPI, giving users a live feed of current stories to analyse directly.

The Problem

Tracking a high-volume job search across multiple platforms quickly became chaotic for me. Applications got lost, interview rounds were not properly logged, and there was no easy way to see patterns across the entire search process, like which roles were moving forward, which were stale, and where time was actually going.

My Solution

I built a Job Application Tracker in React and TypeScript with six application status states, conditional interview round tracking that appears only when relevant, a tag system for filtering by Remote, Referral, and Priority, and per-entry notes. The analytics dashboard shows live counts across all status categories in real time, and an Export to CSV feature makes the data portable. The entire application runs without a backend, using in-memory state management for a fast, private, zero-dependency experience.
